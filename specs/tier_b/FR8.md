# FR8 — stellarator vs tokamak M_KSS (deferred Tier B)

**Claim:** Stellarators (W7-X, LHD) have systematically different M_KSS than
tokamaks, providing a confinement-improvement contrast.

**Data needed:** W7-X and LHD edge diagnostics in a form comparable to FR7's
machine-aggregated table. Some W7-X data is public via the WUI; the cross-
device normalisation is the obstacle.

**Promotion criterion:** Published cross-device confinement compilation
including W7-X edge T_e / n_e.
